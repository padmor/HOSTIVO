# Hostivo

**Smart Hostel Management System**

Hostivo is a secure, reliable, and automation-focused hostel management system designed to reduce manual hostel administration while giving tenants easier access to hostel services.

## Project Direction

Hostivo is being developed in this order:

1. MVP plan
2. System architecture
3. Database/data model
4. Technology decisions
5. SDLC execution
6. Engineering and implementation
7. Testing and security hardening
8. Deployment and operations

## Locked MVP Operating Principle

When accommodation is available:

**Application → Availability Check → Payment → Payment Verification → Automatic Room/Bed Allocation → Occupancy Update → Tenant Activation → Manager Dashboard Update**

Routine available-slot applications do not wait for manual manager approval.

## Core Functions

- Email/password authentication
- Tenant and resident management
- Room and bed management
- Applications and allocation
- Payment management
- Check-in and check-out
- Maintenance management
- Communication and announcements
- Complaints, incidents, and hostel records
- Staff management
- Reports and management information

## Project Status

**Active implementation / production deployment**

Hostivo currently has a deployed Next.js frontend, Supabase-backed authentication and database, role-aware workspaces, accommodation application and payment flows, and automatic bed allocation after payment verification.
